# Planning Session

## Purpose
Plan architecture, tech stack, and tasks without writing production code.

## Steps
1. agentrun init (if not initialized)
2. agentrun start "planning session"
3. Create:
   - PLANNING.md
   - TASKS.md
4. agentrun note "Planned architecture and tasks"
5. agentrun run "git status --short"
6. agentrun report

## Rules
- No heavy coding
- Focus on clarity and structure
- Break work into phases
